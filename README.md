# 📚 AI Research Paper Assistant using RAG and Local LLMs

## Overview

AI Research Paper Assistant is a Retrieval-Augmented Generation (RAG) application that retrieves and answers questions from AI research papers using semantic search and local LLMs.

## Features

* Semantic Search
* FAISS Vector Database
* Phi-3 Mini Local LLM
* Streamlit Web Interface
* Chat History
* Similarity Scores
* Fully Offline Execution

## Tech Stack

* Python
* Streamlit
* FAISS
* Sentence Transformers
* Ollama
* Phi-3 Mini
* Pandas
* NumPy
* PyTorch

## Run the Application

```bash
streamlit run app.py
```

## Example Questions

* What is BERT?
* Explain Retrieval-Augmented Generation.
* How do Vision Transformers work?
* What are diffusion models?
